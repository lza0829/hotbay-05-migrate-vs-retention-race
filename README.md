# 热档片间（Hotbay）

影院素材分区温层：登记 → 冷热迁移 → 保留销毁 → 目录互证。

- 前端 http://127.0.0.1:6300
- API http://127.0.0.1:11300
- `docker compose up -d --build`

## 争用口径：执行中迁移 × 保留扫描

全局只贯彻一种架构——**保留可取消迁移（保留优先）**：

- 保留扫描命中在册分区时，先在同事务内把该分区的执行中迁移单置为「已取消」，再按策略销毁或只标过期；目录与元数据跟销毁结果。
- 取消与销毁双向记账可重放：迁移单备注「保留命中取消，见销毁流水#R」，销毁流水备注「取消迁移单#J」，保留命中回执带 `cancelled_job_id`。
- 已取消单再点完成 → 409 硬拒；完成入口的温层落账与单结清均带状态守卫，并发落空即整体回滚到争用前快照，不留「迁完又毁 / 毁完仍占坑」的半截双终态。
- 若发现分区已非在册而迁移单仍执行中（历史半截），完成入口会同事务补记取消（自愈）后硬拒，总览「迁移执行中」徽章随之闭合。
